# Day 6 - SQL Functions (Introduction)

SQL Functions are built-in methods used to perform calculations, manipulate data, and return results. They help us avoid writing repetitive logic and make queries more powerful and readable.

## What are SQL Functions?
Functions in SQL are predefined commands that take some input (arguments) and return a specific output. They are mainly used to perform operations on data without altering the actual database tables.

## Why are they Important?
- **Data Formatting:** To clean and format data (e.g., converting text to uppercase).
- **Calculations:** To perform mathematical operations like sum, average, etc.
- **Time-Saving:** Reduces the need to write complex logic in application code.

## Types of SQL Functions Covered Today
1. **Aggregate Functions:** Perform calculations on multiple rows and return a single result.
2. **String Functions:** Used to manipulate text data.
3. **Numeric Functions:** Used for mathematical operations.
4. **Date Functions:** Used to handle date and time values.
